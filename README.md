# Focus — A quiet space for focused work.

---

## 🎯 Problem

People often want to work with focus, but simple productivity tools can introduce unnecessary complexity.

Focus provides a small workspace where users can:

- ⏱️ Start a focus session
- 📌 Keep their current tasks visible
- 📊 Track completed sessions
- 💾 Maintain their task list between refreshes

---

## 💡 Solution

Focus combines a minimal timer and task list into a single-page workspace.

The interface intentionally avoids unnecessary features so that the user's attention stays on the current task.

---

## 🤔 Why this approach?

This project was built primarily to refresh and demonstrate core frontend fundamentals:

- 🏷️ Semantic HTML
- 🎨 Modern CSS
- 📱 Responsive layouts
- ⚡ Vanilla JavaScript
- 🔄 DOM manipulation
- 📦 Application state
- 💾 localStorage
- ♿ Accessibility

A framework was intentionally avoided because the application does not have enough complexity to justify one.

## 🏗️ Architecture

The project uses a small modular JavaScript structure:

- 🚀 `app.js` — Application entry point
- 💾 `storage.js` — Persistent application state
- ⏱️ `timer.js` — Timer logic
- 📝 `tasks.js` — Task management
- 🌓 `theme.js` — Theme management
